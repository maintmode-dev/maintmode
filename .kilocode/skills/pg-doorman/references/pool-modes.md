# Режимы пулинга (pool_mode)

## Session Mode

```toml
[pools.maintmode]
pool_mode = "Session"
```

### Когда использовать
- Приложения требующие постоянного соединения
- Prepared statements на уровне сессии
- Длительные транзакции

### Плюсы / Минусы
✅ Полная совместимость с PostgreSQL
✅ Поддержка всех фич
❌ Меньшая эффективность пула
❌ Меньше масштабируемость

## Transaction Mode ⭐ (рекомендуется)

```toml
[pools.maintmode]
pool_mode = "Transaction"
```

### Когда использовать
- Большинство веб-приложений
- REST API сервисы
- Микросервисы
- Короткие транзакции

### Плюсы / Минусы
✅ Высокая эффективность пула
✅ Отличная масштабируемость
✅ Баланс функциональность/производительность
❌ Prepared statements ограничены

## Statement Mode

```toml
[pools.maintmode]
pool_mode = "Statement"
```

### Когда использовать
- Только readonly операции
- Очень короткие запросы
- Максимальная пропускная способность

### Плюсы / Минусы
✅ Максимальная эффективность
✅ Минимальное время удержания
❌ Не поддерживает транзакции
❌ Нет prepared statements
