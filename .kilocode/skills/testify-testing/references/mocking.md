## Generating Mocks

Use mockery to automatically generate mocks from interfaces:

### Installation

```bash
go install github.com/vektra/mockery/v2@latest
```

### Generate Mocks

```bash
# Generate mock for a specific interface
mockery --name=UserStorage --output=./mocks --outpkg=mocks

# Generate mocks for all interfaces in a package
mockery --all --dir=./internal/services --output=./mocks --outpkg=mocks

# With configuration file (.mockery.yaml)
mockery
```

### Example Interface

```go
// internal/storage/user.go
package storage

type UserStorage interface {
    Create(ctx context.Context, user *entity.User) error
    Get(ctx context.Context, id string) (*entity.User, error)
    Update(ctx context.Context, user *entity.User) error
    Delete(ctx context.Context, id string) error
    List(ctx context.Context, filter *Filter) ([]*entity.User, error)
}
```

### Generated Mock

```go
// mocks/UserStorage.go (generated by mockery)
package mocks

import (
    "context"
    "github.com/stretchr/testify/mock"
    "your-project/internal/entity"
    "your-project/internal/storage"
)

type UserStorage struct {
    mock.Mock
}

func NewUserStorage(t interface {
    mock.TestingT
    Cleanup(func())
}) *UserStorage {
    mock := &UserStorage{}
    mock.Mock.Test(t)
    t.Cleanup(func() { mock.AssertExpectations(t) })
    return mock
}

func (m *UserStorage) Create(ctx context.Context, user *entity.User) error {
    ret := m.Called(ctx, user)
    return ret.Error(0)
}

func (m *UserStorage) Get(ctx context.Context, id string) (*entity.User, error) {
    ret := m.Called(ctx, id)
    if rf, ok := ret.Get(0).(func(context.Context, string) *entity.User); ok {
        return rf(ctx, id), ret.Error(1)
    }
    if ret.Get(0) != nil {
        return ret.Get(0).(*entity.User), ret.Error(1)
    }
    return nil, ret.Error(1)
}

// Other methods...
```

## Basic Mock Usage

```go
import (
    "testing"
    "github.com/stretchr/testify/mock"
    "github.com/stretchr/testify/require"
    "your-project/mocks"
)

func TestUserService_Create(t *testing.T) {
    // Create mock
    mockStorage := mocks.NewUserStorage(t)
    service := NewUserService(mockStorage)

    // Setup expectations
    user := &entity.User{ID: "123", Email: "test@example.com"}
    mockStorage.On("Create", mock.Anything, user).Return(nil)

    // Execute
    err := service.Create(context.Background(), user)

    // Assert
    require.NoError(t, err)
    mockStorage.AssertExpectations(t)
}
```

## Mock Expectations

### Basic Expectation

```go
// Expect method to be called with specific arguments
mockStorage.On("Get", ctx, "user-123").Return(user, nil)

// Expect method to be called with any arguments
mockStorage.On("Get", mock.Anything, mock.Anything).Return(user, nil)

// Expect method to be called a specific number of times
mockStorage.On("Get", ctx, "user-123").Return(user, nil).Once()
mockStorage.On("Get", ctx, "user-123").Return(user, nil).Twice()
mockStorage.On("Get", ctx, "user-123").Return(user, nil).Times(3)

// Expect method to never be called
mockStorage.AssertNotCalled(t, "Delete")
```

### Multiple Calls

```go
// Different returns for sequential calls
mockStorage.On("Get", ctx, "user-123").Return(user, nil).Once()
mockStorage.On("Get", ctx, "user-123").Return(nil, ErrNotFound).Once()

// Same call can happen multiple times
mockStorage.On("Create", mock.Anything, mock.Anything).Return(nil).Times(5)
```

### Maybe

```go
// Method may or may not be called
mockStorage.On("Create", mock.Anything, mock.Anything).Return(nil).Maybe()
```

## Argument Matchers

### mock.Anything

Matches any value:

```go
mockStorage.On("Create", mock.Anything, mock.Anything).Return(nil)
```

### mock.AnythingOfType

Matches any value of a specific type:

```go
mockStorage.On("Create",
    mock.AnythingOfType("*context.emptyCtx"),
    mock.AnythingOfType("*entity.User"),
).Return(nil)
```

### mock.MatchedBy

Custom matcher function:

```go
// Match users with specific email domain
mockStorage.On("Create",
    mock.Anything,
    mock.MatchedBy(func(u *entity.User) bool {
        return strings.HasSuffix(u.Email, "@example.com")
    }),
).Return(nil)

// Match non-empty strings
mockService.On("Process",
    mock.MatchedBy(func(s string) bool {
        return len(s) > 0
    }),
).Return(nil)
```

### mock.IsType

Matches argument of a specific type:

```go
mockStorage.On("Create", mock.Anything, mock.IsType(&entity.User{})).Return(nil)
```

## Return Values

### Static Returns

```go
// Return single value
mockStorage.On("Delete", ctx, "user-123").Return(nil)

// Return multiple values
user := &entity.User{ID: "123"}
mockStorage.On("Get", ctx, "123").Return(user, nil)

// Return error
mockStorage.On("Create", mock.Anything, mock.Anything).Return(errors.New("db error"))
```

### Dynamic Returns with Run

```go
mockStorage.On("Create", mock.Anything, mock.Anything).
    Run(func(args mock.Arguments) {
        user := args.Get(1).(*entity.User)
        user.ID = uuid.New().String() // Set ID on creation
        user.CreatedAt = time.Now()
    }).
    Return(nil)
```

### Return Function

```go
mockStorage.On("Get", ctx, mock.Anything).
    Return(func(ctx context.Context, id string) *entity.User {
        if id == "123" {
            return &entity.User{ID: id}
        }
        return nil
    }, func(ctx context.Context, id string) error {
        if id == "123" {
            return nil
        }
        return ErrNotFound
    })
```

## Mock Assertions

### AssertExpectations

Verify all expectations were met:

```go
mockStorage.AssertExpectations(t)
```

### AssertCalled

Verify method was called with specific arguments:

```go
mockStorage.AssertCalled(t, "Create", ctx, user)
mockStorage.AssertCalled(t, "Get", mock.Anything, "user-123")
```

### AssertNumberOfCalls

Verify method was called a specific number of times:

```go
mockStorage.AssertNumberOfCalls(t, "Create", 3)
```

### AssertNotCalled

Verify method was not called:

```go
mockStorage.AssertNotCalled(t, "Delete")
mockStorage.AssertNotCalled(t, "Delete", ctx, "user-123")
```

## Advanced Patterns

### Mocking in MaintMode Clean Architecture

```go
// Service layer test with storage mock
func TestMaintenanceService_Create(t *testing.T) {
    mockStorage := mocks.NewMaintenanceStorage(t)
    mockNotifier := mocks.NewNotifier(t)
    service := services.NewMaintenanceService(mockStorage, mockNotifier)

    ctx := context.Background()
    maint := &entity.Maintenance{
        Title:  "Test",
        Status: entity.StatusPlanned,
    }

    // Setup expectations
    mockStorage.On("Create", ctx, mock.MatchedBy(func(m *entity.Maintenance) bool {
        return m.ID != uuid.Nil && m.CreatedAt.After(time.Time{})
    })).Return(nil)

    mockNotifier.On("NotifyMaintenancePlanned", ctx, mock.Anything).Return(nil)

    // Execute
    created, err := service.Create(ctx, maint)

    // Assert
    require.NoError(t, err)
    require.NotNil(t, created)
    require.NotEqual(t, uuid.Nil, created.ID)
    require.False(t, created.CreatedAt.IsZero())

    mockStorage.AssertExpectations(t)
    mockNotifier.AssertExpectations(t)
}
```

### HTTP Handler Testing with Service Mock

```go
func TestMaintenanceHandler_Create(t *testing.T) {
    e := echo.New()
    mockService := mocks.NewMaintenanceService(t)
    handler := NewMaintenanceHandler(mockService)

    reqBody := `{"title":"Test Maintenance","status":"planned"}`
    req := httptest.NewRequest(http.MethodPost, "/api/maintenances", strings.NewReader(reqBody))
    req.Header.Set(echo.HeaderContentType, echo.MIMEApplicationJSON)
    rec := httptest.NewRecorder()
    c := e.NewContext(req, rec)

    expectedMaint := &entity.Maintenance{
        ID:     uuid.New(),
        Title:  "Test Maintenance",
        Status: entity.StatusPlanned,
    }

    mockService.On("Create", mock.Anything, mock.MatchedBy(func(m *entity.Maintenance) bool {
        return m.Title == "Test Maintenance"
    })).Return(expectedMaint, nil)

    err := handler.Create(c)

    require.NoError(t, err)
    require.Equal(t, http.StatusCreated, rec.Code)
    mockService.AssertExpectations(t)
}
```

### Testing Error Scenarios

```go
func TestUserService_Create_StorageError(t *testing.T) {
    mockStorage := mocks.NewUserStorage(t)
    service := NewUserService(mockStorage)

    expectedErr := errors.New("database connection failed")
    mockStorage.On("Create", mock.Anything, mock.Anything).Return(expectedErr)

    user, err := service.Create(context.Background(), &entity.User{})

    require.Error(t, err)
    require.Nil(t, user)
    require.Equal(t, expectedErr, err)
    mockStorage.AssertExpectations(t)
}
```

## Best Practices

1. **Use mockery for generation** - Don't write mocks by hand
2. **Use NewMock(t) constructor** - Enables automatic expectation assertion
3. **Be specific with matchers** - Use `mock.MatchedBy` for complex validation
4. **Verify expectations** - Always call `AssertExpectations(t)`
5. **Clean mocks between tests** - Recreate mocks in SetupTest when using suites
6. **Mock at boundaries** - Mock external dependencies (storage, APIs, etc.)
7. **Don't over-mock** - Test real implementations when possible
8. **Document complex mocks** - Add comments explaining expectations
9. **Use Maybe() sparingly** - Prefer explicit expectations
10. **Test error paths** - Mock error returns to test error handling

## Common Pitfalls

```go
// BAD: Not asserting expectations
mock.On("Create", mock.Anything, mock.Anything).Return(nil)
service.Create(ctx, user)
// Missing: mock.AssertExpectations(t)

// GOOD: Always assert
mock.On("Create", mock.Anything, mock.Anything).Return(nil)
service.Create(ctx, user)
mock.AssertExpectations(t)
```

```go
// BAD: Reusing mocks between tests (in suites)
type ServiceSuite struct {
    suite.Suite
    mockStorage *mocks.UserStorage // Shared state!
}

func (s *ServiceSuite) SetupSuite() {
    s.mockStorage = mocks.NewUserStorage(s.T()) // Wrong lifecycle
}

// GOOD: Recreate mocks for each test
func (s *ServiceSuite) SetupTest() {
    s.mockStorage = mocks.NewUserStorage(s.T()) // Fresh mock per test
}
```
