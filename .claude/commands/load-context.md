# Load Project Context

Read the project context from `.agent/quick_load.toon` to understand:
- Project type and purpose
- 15 critical rules (all non-negotiable)
- Naming conventions
- Design principles
- Workflow and git conventions
- Error handling patterns
- Testing requirements
- Safety checklist

After loading the main context, you can refer to `.agent/*.md` files for detailed documentation if needed:
- `.agent/branch-naming.md` - Branch naming conventions with examples
- `.agent/commits.md` - Commit message format and guidelines
- `.agent/conventions.md` - Code style and Go conventions
- `.agent/workflow.md` - Development workflow and git practices

## Instructions

1. Read `.agent/quick_load.toon` (TOON format - optimized for fast loading)
2. If you need detailed examples or explanations, read the relevant `.agent/*.md` files
3. Follow all rules marked as `no_exceptions: true`
4. Always check branch before making changes (never commit to main/master)
